# Persona content production matrix and 30-day rotation

Every post must have one audience, one useful insight, one honest project proof point, and one relevant CTA. Posts about historical figures must be independently sourced and reviewed; don't manufacture anecdotes.

## Persona matrix
| Persona | Core question | Tone | Format | CTA | Measurement |
| --- | --- | --- | --- | --- | --- |
| Students | How do I connect names and events? | Curious, empowering | Reels, carousels | Explore one profile | Source-click intent |
| Parents | How can we learn together responsibly? | Warm, grounded | Family prompts | Discuss a reference | Educator feedback |
| Educators | Can this strengthen inquiry? | Pedagogical, precise | Lesson sample, email | Review an exercise | Pilot feedback |
| History enthusiasts | Where does the evidence end? | Exploratory, nuanced | Atlas clip, threads | Review an atlas note | Corrections |
| Reverts/beginners | Where do I start? | Inclusive, clear | Intro carousel | Explore one name | First-read feedback |
| Arabic editors | Is naming/source context precise? | Exact, collaborative | Source audits | Correct one reference | Quality of corrections |
| Scholars | Can I review bounded claims? | Respectful, methodological | Personal email | Scope a review | Verified review records |
| Historians | Are chronology/provenance caveated? | Critical, transparent | Technical essay | Review evidence | Better provenance |
| Developers | Can I contribute meaningful code? | Concrete, technical | GitHub walkthrough | Open issue/PR | Useful merged PRs |
| Accessibility advocates | Can everyone participate? | Practical, inclusive | Test challenge | File reproducible bug | Resolved defects |
| Muslim builders | How do community ideas become tools? | Mission-led, celebratory | Founder story | Invite collaborator | Sustained contributors |
| Organizations | Can we evaluate without endorsement? | Professional, cautious | One-page pilot | Agree small evaluation | Pilot insights |

## Video production formula
0–3 sec: audience question; 3–10 sec: recognizable learning pain; 10–22 sec: one grounded capability; 22–30 sec: evidence limit; 30–38 sec: one action. Capture real UI if verified. Never fake product screenshots as live footage.

## Conversion pages to build later (proposals, not live routes)
- For students: a guided reading sequence.
- For educators: bounded classroom exercise and feedback intake.
- For historians/scholars: sourcing policy and review queue.
- For developers: current issues and test workflow.
- For institutions: pilot proposal with clear non-endorsement language.

## Experiment design
Test question-first vs community-first headlines, atlas-led vs source-led graphics, short vs long descriptions, GitHub direct vs contribution-guide deep link. Hold each channel and audience constant when possible; evaluate meaningful review and contributor quality rather than viral reach alone.

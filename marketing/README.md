## Ground truth
The README currently describes 81 profiles, 25 commonly taught prophets, 16 atlas chapters (per CHANGELOG), source-linked content, uncertainty labels, searchable categories, random discovery, Saved Lives, shareable URLs, a Three.js atlas with 0.5x/1x/2x playback, crawlable pages, and an Expo SDK 57 codebase. These are repository-documented features, **not an assertion that a production website or mobile app is publicly launched**.

**Important:** no license is presently declared. Public source does not automatically make code open-source in the licensed sense. Do **not** announce 'open source', 'MIT licensed', 'freely reusable', 'app now on stores', 'scholar-verified', 'complete', or 'historically exact' until verified and approved. Proposed language: 'public GitHub project welcoming contributions'. Once maintainers adopt an approved open-source license, update the campaign accordingly.

**Credit:** community-member contribution is described by project stakeholders, but the member's preferred display name and permission for attribution must be confirmed; use 'a member of our community' until then.

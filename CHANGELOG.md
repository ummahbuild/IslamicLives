# Changelog

Notable project changes are recorded here. Until the first public release is approved, entries remain under **Unreleased**.

## Unreleased

### Added

- Crawlable pages for 81 profiles and 16 atlas chapters.
- Named-Surah Qur’an citations and structured editorial-review status.
- Web and Expo discovery, saved profiles, sourced biographies, and atlas parity.
- A deterministic 100-point production contract and performance budgets.

### Changed

- Date charts now appear only for supported years within their displayed range.
- Unsupported locations no longer render suggestive placeholder maps.
- Atlas code and data load only when the atlas or supported modern-date context is requested.
- Direct atlas chapters retain their sourced HTML if interactive enhancement fails.
- Atlas chapters now update the page title, announce changes, preserve cumulative routes on first render, and link to adjacent chapters.

### Accuracy boundaries

- Structural and citation checks do not constitute qualified scholarly review.
- Native device, VoiceOver, TalkBack, and exhaustive corpus coverage remain pending.
